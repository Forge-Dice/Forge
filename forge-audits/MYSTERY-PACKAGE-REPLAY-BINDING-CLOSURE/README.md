# Mystery V1 package/replay closure lab

Contract-only closure against immutable GitHub audit originals. No production implementation or production conformance certification. D1–D10 are accepted by the owner instruction for this lab; D9 assigns package/public-content/adapter ownership to Session A, D10 binds public text and permits false/undetermined allowedClaims.

Run with Node 22+ and Python 3: `node lab.mjs` then `python verify-vectors.py`. No dependencies, network, imported repository code or executable authoring inputs. Outputs are deterministic; generated JSON is evidence from a deliberately finite contract model, not production output. Golden verification uses a separately written Python serializer/digest implementation.

The report, registry and exact repair table together define the scoped V1 closure. Repairs target existing Session A/B/C ownership and do not add a new package task. Original sources remain unchanged. Source manifest records fixed audit commits, paths, Git blob IDs and independently verified byte SHA-256. Canonical schema/identity files were read from the Session audit commit's unchanged baseline files.

Mutation results distinguish a valid changed artifact producing a different package ID from structurally invalid or foreign-bound artifacts rejected at resolution. Save mismatch is then tested separately. Histories exercise the accepted three-event vocabulary through a small explicit host model. These are binding/ordering/atomicity properties, not a new implementation of nine-claim NPC reasoning or Solvability.

Resource numbers copied from already explicit Session/component contracts remain scoped contract budgets, not measurements or adopted VS-5 scratch limits. Unspecified numerical bounds remain OPEN BOUND.
